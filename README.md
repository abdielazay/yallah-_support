# Yallah! — Support Pages

This repository hosts the public **Support URL** for the Yallah! app (GitHub Pages).
It includes:
- `index.html`: Support + How to use + FAQ
- `privacy.html`: Privacy Policy
- `styles.css`: Minimal styling
- `README.md`

## Publish on GitHub Pages
1. Create a new public repo (e.g., `yallah-support`).
2. Upload these files to the repo root.
3. Go to **Settings → Pages**.
4. **Source**: select `main` and folder `/ (root)` → **Save**.
5. Your site will be at `https://<your-user>.github.io/yallah-support/`.

## Customize
- Update email, FAQs, and copy any time.
- No build tools required; it's static HTML/CSS.
- If you add analytics or cloud sync features to the app later, remember to update the copy and your App Store `App Privacy` questionnaire.
